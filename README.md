# Our Love Story — حكايتنا

موقع ثابت عربي RTL لتخصيص قصة الحب. لا توجد بيانات شخصية افتراضية أو قاعدة بيانات.

## النشر
من Settings → Pages اختر Deploy from a branch، ثم main و / (root)، ثم Save.
الرابط المتوقع: https://yoyo-kandeel.github.io/f/

## الاستخدام
- افتح الموقع وأدخل الاسمين وتاريخ البداية (الوقت اختياري).
- أضف الذكريات والصور والرسائل والأحلام والمفاجأة اختياريًا.
- حفظ ومعاينة يحفظ مسودة في المتصفح، ويمكن العودة إلى صفحة التعديل عبر ?edit=1.
- إنشاء رابط مشاركة يضم البيانات النصية وروابط الصور HTTPS في جزء الرابط #story=. لا يحمّل بيانات إلى المستودع ولا يزامن التعديلات.
- الصور من الجهاز تُضغط محليًا ويمكن تضمينها في نسخة HTML قابلة للمشاركة. افتح النسخة المصدّرة في المتصفح. التصدير من الموقع المنشور يتطلب اتصالًا لتحميل القالب؛ الخطوط الخارجية والوسائط المرتبطة قد تحتاج الإنترنت عند العرض.
- لتشغيل الموسيقى أضف رابط HTTPS مباشر لملف صوتي.
- روابط المشاركة ليست مشفرة أو محمية بكلمة مرور؛ لا تشارك محتوى حساسًا دون موافقة صاحبه.
